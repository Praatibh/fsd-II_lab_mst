# Part B: Practical

Create a simple React Login System that:

- Contains username and password fields.
- Provides a Login button.
- After successful login, creates a simulated JWT/token containing `userId` and `role`.
- Stores the token.
- Displays the user's role after login.
- Shows a protected Dashboard only when the user is logged in.

**Concepts:** Authentication, JWT, Token Generation, Token Storage, Protected UI
